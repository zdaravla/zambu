Spojení s Infoc

Jak vytvořit klíč
  1. Na počítači otevřete github.com/settings/personal-access-tokens/new.
  2. Název ZAMBU, platnost 90 dní.
  3. Repository access: Only select repositories → infoc.
  4. Permissions → Repository → Contents: Read and write. Nic dalšího.
  5. Vytvořit, zkopírovat a vložit sem (přes AirDrop nebo poznámku, ne mailem).
